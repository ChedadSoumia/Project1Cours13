# 🧩 Doubly Linked List in C++ (Template Version)

A fully functional **Doubly Linked List** implemented in modern C++ using templates.  
This project demonstrates how to build and manipulate a dynamic data structure manually using pointers and OOP principles.

---

## 🚀 Features

- Add elements at the **beginning**, **end**, or **after** any node.
- **Delete** the first, last, or specific node.
- **Search** for elements efficiently.
- **Reverse** the list in-place.
- **Update** items by index.
- **Clear** all elements safely.
- Works with **any data type** thanks to templates.

---

## 🧠 Concepts Covered

- Pointers and dynamic memory (`new`, `delete`)
- Template programming (`template <typename T>`)
- Doubly linked node structure (`Next` and `Prev`)
- Basic OOP principles in C++
